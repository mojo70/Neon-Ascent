# Master Shower Replacement Project Plan

**Alcove:** 36.5 in wide x 45.5 in deep (to studs)
**Drain:** Centered on 36.5 in depth (offset from full depth)
**Style:** Modern spa walls + hippie-eclectic mosaic floor (resale-friendly)
**Approach:** DIY custom Kerdi pan + tiled walls
**Estimated materials total:** $1,400 – $2,400

## Project Plan (tagged by phase)

### Phase 1: Demo & Prep
- Remove old drop-in unit and any damaged drywall
- Inspect subfloor and framing; repair as needed
- Confirm drain location and rough-in height

### Phase 2: Pan & Drain  <!-- materials: Kerdi-Shower tray, Kerdi-Drain, thinset -->
- Set Kerdi-Shower pre-sloped tray on thinset bed (¼" per ft slope toward drain)
- Install Kerdi-Drain flange, connect to existing drain line
- Waterproof pan with Kerdi membrane + Kerdi-Band seams

### Phase 3: Wall Substrate  <!-- materials: HardieBacker, screws, mesh tape -->
- Screw HardieBacker to studs over pan curb
- Tape seams with mesh tape + thinset

### Phase 4: Waterproofing  <!-- materials: Kerdi membrane, Kereck corners, Kerdi-Fix -->
- Apply Kerdi membrane to walls, overlapping pan by 2"
- Use Kereck corners at inside/outside transitions
- Seal all seams with Kerdi-Fix

### Phase 5: Tile Floor  <!-- materials: 1" hex mosaic, thinset, grout -->
- Tile pan floor with hex mosaic (terracotta/sage)
- Grout floor, seal

### Phase 6: Tile Walls  <!-- materials: 12x24 porcelain, zellige accent, thinset, grout -->
- Tile walls with large-format beige stone-look porcelain
- Add zellige accent in niche or feature strip
- Grout walls, seal

### Phase 7: Plumbing & Trim  <!-- materials: valve, fittings, edge trim, sealant -->
- Install pressure-balance valve and trim
- Connect PEX/copper supply lines
- Install edge trim, caulk joints, final seal

### Phase 8: Finish & Cure
- Allow grout/thinset to cure (typically 24–72 hrs)
- Test for leaks
- Install glass door or curtain as desired

## Notes
- Foam tray route is faster and more forgiving than a full mud bed for first-timers.
- Keep palette earthy: ochre, cinnamon, soft green — modern enough for resale, personal enough for you.
- Total DIY materials: ~$1,400–$2,400 depending on tile grade.
